​ติดตั้ง Termux ใหม่: โหลดจาก F-Droid 
​อัปเดตระบบให้พร้อม (พิมพ์ทีละแถว):

​pkg update && pkg upgrade -y

​termux-setup-storage 

(แล้วกดอนุญาตให้เข้าถึงไฟล์)

​ติดตั้งโปรแกรม ​ติดตั้งภาษา Go: 

pkg install golang -y

​ติดตั้งตัวแปลงภาพ:

go install github.com/TheZoraiz/ascii-image-converter@latest


​วิธีแก้ปัญหาบัค "หาคำสั่งไม่เจอ" 

เพื่อให้เรียกใช้ ascii-image-converter ได้ตลอดโดยไม่ต้องพิมพ์ PATH ใหม่ทุกครั้ง ให้พิมพ์คำสั่งนี้:

​echo 'export PATH=$PATH:$(go env GOPATH)/bin' >> ~/.bashrc && source ~/.bashrc

​หลังจากนี้ ไม่ว่จะปิดแอปแล้วเปิดใหม่กี่ครั้งก็จะสามารถพิมพ์คำสั่งใช้งานได้ทันที:

​ascii-image-converter [ชื่อไฟล์รูป] -b

คำอธิบายเพิ่มเติม:
​~/storage/downloads/ คือที่อยู่มาตรฐานของโฟลเดอร์ดาวน์โหลดในมือถือที่ Termux มองเห็น
​-b: คือเทคนิคเพื่อให้ภาพออกมาเป็น "จุดเบรลล์"

​-d 40,20: คือการกำหนดขนาดภาพ (กว้าง 40 จุด, สูง 20 จุด) สามารถปรับตัวเลขนี้ให้เล็กลงหรือใหญ่ขึ้นตามขนาดหน้าจอได้เลย

ถ้าอยากให้ภาพออกมามีสีให้เติม -c ต่อท้ายคำสั่ง
