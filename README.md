ขั้นตอนที่ 1: 
การติดตั้งและเตรียมระบบ (The Setup)

​โหลดแอป: แนะนำให้โหลด Termux จาก F-Droid เพื่อให้ได้เวอร์ชันล่าสุดที่รองรับการใช้งานใหม่ๆ

​อัปเดตระบบ:
เมื่อเข้าแอปครั้งแรก ให้พิมพ์คำสั่งนี้:

​apt update && apt upgrade -y

ถ้าค้างโหลดไม่เสร็จ ให้กด y แล้วกดเอ็นเตอร์

​จุดที่คนมักเจอ:
ถ้าพิมพ์ pkg แล้วขึ้นว่าไม่เจอคำสั่ง ให้ใช้ apt 

​ขอสิทธิ์เข้าถึงไฟล์:
เพื่อให้ Termux มองเห็นรูปในมือถือเรา:

​termux-setup-storage

ต้องกด "อนุญาต/Allow" ที่หน้าจอโทรศัพท์

​📦 ขั้นตอนที่ 2:
ติดตั้งตัวแปลงภาพ (The Installation)

​ติดตั้งภาษา Go:

​apt install golang -y

​ติดตั้ง ascii-image-converter:

​go install github.com/TheZoraiz/ascii-image-converter@latest

​⚠️ ขั้นตอนที่ 3:
วิธีแก้ปัญหา "หาคำสั่งไม่เจอ" (Troubleshooting Path) ​นี่คือจุดที่คนส่วนใหญ่จะติด! เมื่อลงเสร็จแล้วลองพิมพ์ชื่อโปรแกรมแล้วมันขึ้นว่า command not found วิธีแก้ เราต้องบอกทางไปหาโปรแกรมให้เครื่องรู้ โดยพิมพ์:

​export PATH=$PATH:$(go env GOPATH)/bin

​เช็คความชัวร์พิมพ์ :
ascii-image-converter -v 

ถ้าขึ้นเลขเวอร์ชันออกมา แสดงว่าผ่าน!

​🖼 ขั้นตอนที่ 4: 

การแปลงรูปภาพเป็นจุดเบรลล์ (The Magic)
​เมื่อระบบพร้อมแล้ว เวลาจะแปลงรูปต้องระบุ "ที่อยู่ไฟล์" ให้ถูก..คำสั่งพื้นฐาน:

​ascii-image-converter [ที่อยู่ไฟล์รูป] -b -d 40,20

​ความหมายของตัวช่วย (Flags):

​-b: เปลี่ยนภาพเป็น "จุดเบรลล์" (ที่คุณอยากได้)

​-d 40,20: ปรับขนาดให้พอดี (กว้าง 40 สูง 20)

​-c: ถ้าอยากให้ภาพมีสีเหมือนจริงให้เติมตัวนี้

​💡 หาไฟล์ไม่เจอ? (File Directory Tips)
​จุดสังเกต: ถ้าขึ้น no such file or directory ให้เช็คดูดีๆ ว่ารูปอยู่ในโฟลเดอร์ไหน
​ถ้าอยู่ในโฟลเดอร์ดาวน์โหลด: ~/storage/downloads/...
​ถ้าอยู่ในโฟลเดอร์รูปภาพ: ~/storage/pictures/...
​ตัวช่วย: ใช้คำสั่ง ls ตามด้วยที่อยู่โฟลเดอร์ เพื่อดูว่ามีชื่อไฟล์รูปเราอยู่ในนั้นจริงๆ ไหม
